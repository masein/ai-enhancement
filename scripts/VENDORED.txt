Code here that others wrote, kept as they wrote it: where each came from, at
what version, under what licence, and what was changed. Each changed line is
marked in its file, and a test undoes the changes and compares the result
with the source, byte for byte. Nothing in these folders is downloaded or
built at run time; NLTK's data they read is in the image (scripts/nltk_data.py).
